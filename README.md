# Numerical Linear Algebra Portfolio

A collection of three Jupyter Notebooks where I used Python to solve, analyze, and visualize math and linear algebra problems. This repository shows how I practice programming math concepts using code during my first year.

## 🛠️ Tools I Used
* **NumPy:** A Python library I used to create grids of numbers, vectors, and matrices.
* **SymPy:** A library that helps print out exact fractions and solve matrix step-by-step math (RREF).
* **Matplotlib:** A tool used to draw graphs and shapes so I can see how the math transformations look visually.

## 📁 What is Inside the Notebooks

### 1. Matrix Multiplication (`linear_algebra_matrix_computations.ipynb`)
* Explores how computers multiply matrices together.
* Compares two different ways to write the code (row-by-column versus combining whole columns).
* Uses a timer to see which coding method runs faster on my computer.

### 2. Systems & Nullspace Solver (`linear_algebra_systems_and_nullspace.ipynb`)
* Automatically solves math equations using step-by-step matrix reduction.
* Finds independent lines and core vectors in a matrix grid.
* Uses random numbers to prove that the math formula Ax = 0 works correctly in code.

### 3. Geometric Transformations (`linear_algebra_transformations.ipynb`)
* Applies math matrices to 2D shapes to move them around.
* Programs code to handle shape rotations, resizing (scaling), and slanting (shearing).
* Displays a side-by-side graph showing the shape before and after the math changes it.
